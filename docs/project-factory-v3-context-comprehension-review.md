# Project Factory V3 — Context-Comprehension Review

Status: **preliminary desk review; participant validation still required**

Date: 2026-08-22

## Purpose

This review tests whether a learner without manufacturing-plant experience can
make a bounded Window 1 Research decision from the scenario pack alone. It is a
learner-context review, not an operations validation and not evidence that the
content is factually calibrated.

## Review standard

The reviewer should be able to answer without private plant knowledge:

1. What problem is being addressed?
2. What is known and what is unknown?
3. What will Research establish?
4. What would make a later Pilot possible?
5. What will not change immediately?
6. What capital/capacity is being committed?
7. What happens if the learner defers?

The reviewer should not need to infer meaning from an initiative name, guess a
branch, or understand an internal factory acronym. The pack is the operating
truth for the exercise.

## Method used

This is a document-based cognitive walkthrough of the revised Orient, Compare,
Commit, remediation packet, branch outcome, and Next Window materials. It is
labelled preliminary because it has not yet been run with an independent
non-manufacturing participant.

## Required design corrections before participant walkthrough

1. Add a persistent capacity legend to the Window 1 context strip:
   `1/4 = one unit used of four available units in that pool.`
2. Add the same timing line to all three Compare packets:
   `Research activity Q1 · signal available Q2 · board review at end of Q3.`
3. Change the deferral copy to `If you defer now` and name the next review
   trigger in the same sentence.
4. Add one plain-language term beside each packet's first technical term; the
   drawer may contain the longer glossary.
5. Keep the visible packet summary compact. The full fact list, limitations,
   and source excerpts remain in contextual disclosure.

## Participant walkthrough protocol

Run this with 3–5 representative learners/facilitators, including at least one
person who does not work in manufacturing. Do not explain the answer before the
attempt.

For each participant, ask them to:

1. choose one Research priority;
2. explain what the Research spend will discover;
3. state one thing that will not change yet;
4. explain what would make Pilot available;
5. describe the consequence of deferring;
6. identify the primary action that advances the state.

Record wrong turns, prompts required, terms misunderstood, time spent, and
whether the participant opens the full evidence drawer unnecessarily. Do not
score whether the participant guessed the resolver branch.

## Acceptance threshold

The context layer passes when most participants can answer all six questions
without facilitator explanation, can distinguish Research from Pilot, and can
identify the next primary action. If they cannot, add context or simplify the
packet; do not add a recommendation or make the branch predictable.

## Current decision

The revised context contract is directionally correct and materially better than
the prior packet design, but UX-W1-08 remains open until the four corrections are
applied and the participant walkthrough is completed. Production implementation
remains paused.
